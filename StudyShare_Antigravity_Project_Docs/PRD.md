# StudyShare — Product Requirements Document

## Product
StudyShare — student knowledge-sharing and study-resource platform.

## Vision
Help students discover, organize, share and discuss high-quality study resources through a simple, responsive and community-oriented platform.

## Users
### Guest
Can browse, search and open public notes.

### Student
Can save, like, rate, comment, download, upload resources, manage profile and ask doubts.

### Teacher
Can upload and manage educational resources and participate in the knowledge-sharing ecosystem.

### Admin
Can moderate and manage users, notes, comments, categories, reports and platform content.

## Core Modules
- Authentication
- Home
- Explore/search
- Notes
- Upload/edit/delete
- Dashboard
- Profile
- Bookmarks
- Likes
- Ratings
- Comments
- Notifications
- Doubts
- Teacher resources
- Community
- Admin panel

## Resource Types
- PDF
- PPT/PPTX
- Images
- Notes/text
- PYQs
- Video/reference links
- Summarized notes

## Non-functional Requirements
- Responsive
- Secure
- Maintainable
- Server-side rendered with EJS
- MongoDB/Mongoose
- Strong validation
- Centralized errors
- Accessible forms
- Good empty/error/success states
- No dead UI controls

## UI Direction
Preserve the existing StudyShare dark navy/purple visual system and component hierarchy.

## Acceptance Criteria
A feature is accepted only when:
1. Its route exists.
2. Its UI exists.
3. Validation exists.
4. Authorization exists where required.
5. Database behavior works.
6. Error/success feedback exists.
7. Desktop works.
8. Mobile works.
9. The feature has been manually verified.
